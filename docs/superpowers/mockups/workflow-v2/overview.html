2. Job Workflow — Before vs After

Before (current)

1
Sales creates job (pending)
↓
2
Sales clicks "Push for Approval"
Status → awaiting_approval
↓
3
Scheduler reviews in Approvals queue
Can approve or send back
↓
4
Scheduler approves → scheduled
Installer notified via Telegram

After (Workflow V2)

1
Sales creates job (pending)
Can suggest preferred installers (yellow)
↓
2
Sales clicks "Push to Schedule"
Status → scheduled directly. No approval queue.
↓
3
Scheduler / Coordinator gets Telegram notification
"New job — assign installer"
↓
4
Coordinator / Scheduler formally assigns installer (green)
Sales + Coordinators notified via Telegram

Note: "awaiting_approval" status is kept in the database for existing historical jobs — no new jobs will ever enter that state.

4. What Gets Built (4 Phases)

Phase 1 — Foundation
Roles + Workflow Change
  • 3 new DB roles: Designer, Coordinator, Production
  • Sales → "Push to Schedule" (no approval queue)
  • Scheduler gets Telegram on new job
  • FCFS tab in nav (scheduler + coordinator)
  • Approvals tab removed
Phase 2 — Job Form
Role Permissions + Installer Assignment
  • Each role sees only fields they can edit
  • Sales: suggest installer (yellow card)
  • Coordinator/Scheduler: formally assign (green card, clears suggestions)
  • Sales notified when installer is assigned
  • Production: ticks "production ready" + uploads photos
Phase 3 — FCFS Board
Weekly Timeline + Clash Detection
  • Weekly grid: installer rows × day columns
  • Job blocks show FCFS rank (#1, #2…)
  • Clashing jobs highlighted red
  • Clash drawer: see which job was first (priority)
  • Coordinator clash prompt: alert scheduler or re-assign
Phase 4 — Advanced Features
External Links + Sub-installer + Tasks
  • External temp link: 48hr shareable (no login required)
  • Expired link shows "contact person-in-charge" message
  • Sub-installer: supporting installer on a job
  • Task list: add tasks (sales/coord/sched), tick (installer)
  • External installer POC bucket (outsourced teams)

This is the overview. Next screens will show each area in detail — FCFS Board, job form per role, installer cards, and more.
