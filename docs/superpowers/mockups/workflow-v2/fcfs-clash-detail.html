Summary of Clash Drawer Behaviour

1 clash: Drawer opens directly to the detail view — both job cards side by side, time overlap bar, Re-assign + Dismiss buttons.
2+ clashes: Drawer opens to a list — each clash as a row showing installer + day + job titles. Tap any row to drill into that clash's detail view.
Priority (green border): Job created first — keeps its slot. No action needed on this one.
Re-assign (red border): Job created second — the "Re-assign Job #X →" button takes you straight to that job's edit form to pick a different installer.
Dismiss: Hides the clash from the board for this session only. It reappears on next load if the assignment isn't changed.
