External Installer — Persistent Link

One link per person, forever. Shared once, works across all jobs.
How it works: When the coordinator first adds David as an external installer, a unique link is generated once — greenqubes.com/ext/x9k2m. David bookmarks it. Every job assigned to him appears on his homepage automatically. No new links, no confusion.

DB requirement: Minimal — name, phone, and a token per person. That's it. The token is their identity. No login, no password.
