> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Nic's standing rule 2026-09-04: inline execution, no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hands-free voice assistant — big floating mic button on every page opens a full-screen voice mode where the user talks, the existing assistant answers out loud, and jobs get created by voice via the existing `create_pending_job`.

**Architecture:** A client-side voice shell (Web Speech API `SpeechRecognition` in + `speechSynthesis` out) around the untouched `/api/assistant/chat` SSE agentic loop. Four pure, standalone-tested modules (lang mapping, markdown→speakable stripper, sentence chunker, conversation state machine) + one hook wiring browser speech to the SSE stream + overlay UI + FAB. One additive server change: a `voice` flag that appends a reply-style line to the *uncached* volatile system block.

**Tech Stack:** Next.js 15 App Router, TypeScript strict, Tailwind (design tokens), Web Speech API, existing Anthropic SSE route (`claude-sonnet-5`). No new dependencies, no migration.

**Spec:** `docs/superpowers/specs/2026-09-04-voice-pa-design.md`

```ts
// src/features/voice/voiceLang.ts
import type { LangCode } from '@/lib/i18n'

// Some platforms (Android WebView, older Chrome) report voice langs with an
// underscore ("zh_CN") — normalise before comparing.
export interface SpeakableVoice { name: string; lang: string; localService: boolean }

// Same mapping the composer dictation mic uses: zh → Mandarin, everything
// else → Singapore English (bn voice is out of scope v1 — spec §2.3).
export function speechLangTag(lang: LangCode): string {
  return lang === 'zh' ? 'zh-CN' : 'en-SG'
}

// Exact-tag matches beat language-prefix matches; local voices beat remote
// within each tier (no network dependency, no first-utterance lag).
export function pickVoice(voices: SpeakableVoice[], tag: string): SpeakableVoice | null {
  const norm   = (l: string) => l.replace('_', '-').toLowerCase()
  const target = norm(tag)
  const prefix = target.split('-')[0]
  const rank = (v: SpeakableVoice): number => {
    const vl = norm(v.lang)
    if (vl === target) return v.localService ? 0 : 1
    if (vl.split('-')[0] === prefix) return v.localService ? 2 : 3
    return 4
  }
  const best = [...voices].sort((a, b) => rank(a) - rank(b))[0]
  return best && rank(best) < 4 ? best : null
}
```

```ts
// src/features/voice/speakable.ts

// Turns one chunk of assistant markdown into text a speech voice can read
// naturally. The voice-mode prompt asks the model for plain prose, but the
// model can still slip in markdown — this is the safety net, not the plan.
// Order matters: links before bare URLs, block markers before inline ones.
export function toSpeakable(text: string): string {
  return text
    .replace(/!\[[^\]]*\]\([^)]*\)/g, '')            // images (drop entirely)
    .replace(/\[([^\]]+)\]\([^)]*\)/g, '$1')          // links → label
    .replace(/https?:\/\/\S+/g, '')                   // bare URLs
    .replace(/^#{1,6}\s+/gm, '')                      // heading markers
    .replace(/^\s*(?:[-*+]|\d+[.)])\s+/gm, '')        // bullet / numbered markers
    .replace(/^(?:-{3,}|_{3,}|\*{3,})\s*$/gm, '')     // horizontal rules
    .replace(/```[^`]*```/gs, '')                     // fenced code blocks
    .replace(/`([^`]*)`/g, '$1')                      // inline code → contents
    .replace(/(\*\*|__)(.*?)\1/g, '$2')               // bold
    .replace(/(\*|_)(.*?)\1/g, '$2')                  // italic
    .replace(/^\s*\|(.+)\|\s*$/gm, (_, row: string) => // table row → "a, b"
      row.split('|').map(c => c.trim()).filter(c => c && !/^:?-+:?$/.test(c)).join(', '))
    .replace(/[\p{Extended_Pictographic}\uFE0F\u200D]/gu, '') // emoji + joiners
    .replace(/\s+/g, ' ')
    .trim()
}
```

```ts
// src/features/voice/sentenceChunker.ts

// Accumulates SSE text deltas and emits complete sentences so speech can
// start before the stream finishes. Latin enders (. ! ?) count only when
// followed by whitespace/end-of-buffer — this keeps decimals ("2.5") and
// times intact; CJK enders (。！？) and newlines are boundaries on their own.
export function createSentenceChunker(): { push(delta: string): string[]; flush(): string | null } {
  let buffer = ''

  function extract(): string[] {
    const out: string[] = []
    // Walk the buffer for the earliest boundary each pass.
    for (;;) {
      let cut = -1
      for (let i = 0; i < buffer.length; i++) {
        const ch = buffer[i]
        if (ch === '\n' || ch === '。' || ch === '！' || ch === '？') { cut = i; break }
        if ((ch === '.' || ch === '!' || ch === '?') &&
            (i + 1 < buffer.length) && /\s/.test(buffer[i + 1])) { cut = i; break }
      }
      if (cut === -1) break
      const sentence = buffer.slice(0, cut + 1).trim()
      buffer = buffer.slice(cut + 1)
      if (sentence) out.push(sentence)
    }
    return out
  }

  return {
    push(delta: string): string[] {
      buffer += delta
      return extract()
    },
    flush(): string | null {
      const tail = buffer.trim()
      buffer = ''
      return tail || null
    },
  }
}
```

```ts
// src/features/voice/voiceMachine.ts

// Pure reducer for the hands-free loop. The hook owns the side effects
// (start/stop recognition, speak, fetch); this owns WHEN. Key invariant:
// 'responding' ends only when streamDone AND speechDone — the SSE stream
// and the TTS queue drain in either order.
export type VoicePhase = 'listening' | 'responding' | 'muted' | 'tapToTalk'

export interface VoiceState {
  phase:      VoicePhase
  streamDone: boolean
  speechDone: boolean
  restarts:   number
  // Where to return after a reply finishes ('muted' returns to muted, the
  // degraded mode returns to tapToTalk, normal flow to listening).
  home:       'listening' | 'muted' | 'tapToTalk'
}

export type VoiceEvent =
  | { type: 'utteranceReady' }
  | { type: 'streamEnded' }
  | { type: 'speechDrained' }
  | { type: 'recEnded' }
  | { type: 'recFatal' }
  | { type: 'mute' }
  | { type: 'unmute' }

export const MAX_RESTARTS = 3

export const initialVoiceState: VoiceState = {
  phase: 'listening', streamDone: false, speechDone: false, restarts: 0, home: 'listening',
}

function settle(s: VoiceState): VoiceState {
  if (s.phase === 'responding' && s.streamDone && s.speechDone) return { ...s, phase: s.home }
  return s
}

export function voiceReducer(s: VoiceState, e: VoiceEvent): VoiceState {
  switch (e.type) {
    case 'utteranceReady':
      if (s.phase !== 'listening' && s.phase !== 'tapToTalk') return s
      return { ...s, phase: 'responding', streamDone: false, speechDone: false, restarts: 0 }
    case 'streamEnded':
      return settle({ ...s, streamDone: true })
    case 'speechDrained':
      return settle({ ...s, speechDone: true })
    case 'recEnded': {
      // Only meaningful while we WANT the mic on; during 'responding' we
      // stopped it ourselves. Chrome ends continuous recognition ~60s idle
      // and on network blips — budget MAX_RESTARTS before degrading.
      if (s.phase !== 'listening') return s
      const restarts = s.restarts + 1
      if (restarts >= MAX_RESTARTS) return { ...s, phase: 'tapToTalk', home: 'tapToTalk', restarts: MAX_RESTARTS }
      return { ...s, restarts }
    }
    case 'recFatal':
      return { ...s, phase: s.phase === 'responding' ? 'responding' : 'tapToTalk', home: 'tapToTalk' }
    case 'mute':
      return { ...s, phase: s.phase === 'responding' ? 'responding' : 'muted', home: 'muted' }
    case 'unmute':
      return { ...s, phase: s.phase === 'responding' ? 'responding' : 'listening', home: 'listening', restarts: 0 }
  }
}
```

Note the test `'mute while responding lets reply finish'` expects `phase: 'muted'` immediately — reconcile: the DESIGN is that muting during a reply lets speech finish but the mic must never reopen. Simplest correct behaviour: mute during `responding` switches `home` to `'muted'` but keeps phase `responding` — the test above asserting `'muted'` is wrong for that design. **Use the reducer's behaviour as written and fix the two mute tests to match:**

```ts

check('after reply, lands muted', run(responding, { type: 'mute' }, { type: 'streamEnded' }, { type: 'speechDrained' }).phase, 'muted')
```

```ts
export interface VoiceTurn { id: string; role: 'user' | 'assistant'; content: string; jobCard?: { id: string; title: string | null } }
export function useVoiceSession(lang: LangCode): {

  supported: { stt: boolean; tts: boolean }
  micDenied: boolean
  liveTranscript: string          // interim words while listening
  turns: VoiceTurn[]              // finished turns, newest last

```

- [ ] **Step 1: Write the hook.** Full implementation requirements — each maps to a spec section:

```ts
// src/features/voice/useVoiceSession.ts
'use client'
```

1. **Local Web Speech typings** — copy the minimal `SpeechRecognition` interface pattern from `AssistantShell.tsx:52-76` (constructor via `window.SpeechRecognition ?? window.webkitSpeechRecognition`); add minimal `speechSynthesis`/`SpeechSynthesisUtterance` usage (those ARE in lib.dom — no typings needed).
2. **State:** `useReducer(voiceReducer, initialVoiceState)` + `useState` for `liveTranscript`, `turns`, `streamingText`, `statusKey`, `errorKey`, `micDenied`; refs for recognition instance, AbortController, chunker, utterance queue count, silence timer, `phaseRef` (mirror of `phase` for use inside recognition callbacks), and `voicesRef` (loaded voices).
3. **`start()`** (user gesture): detect support (`stt` = constructor present, `tts` = `'speechSynthesis' in window`); **unlock iOS TTS** by speaking an empty utterance (`speechSynthesis.speak(new SpeechSynthesisUtterance(''))`); load voices with the `voiceschanged` listener fallback (`getVoices()` may be empty on first call); begin listening (unless no STT → the overlay shows type-to-talk; no recognition started).
4. **Listening:** create recognition with `continuous = true`, `interimResults = true`, `lang = speechLangTag(lang)`. `onresult`: rebuild the full transcript from `e.results` (final + interim, the AssistantShell concat pattern); show it via `setLiveTranscript`; when the latest result `isFinal`, (re)start a **1200 ms silence timer** — on fire, take the final transcript, clear interim, and send. New results cancel the pending timer. `onend`: if `phaseRef.current === 'listening'`, dispatch `{type:'recEnded'}` and, if the reducer stays in `listening`, recreate + restart recognition. `onerror`: `'not-allowed'`/`'service-not-allowed'` → `setMicDenied(true)` + dispatch `recFatal`; other errors → treat as `recEnded`.
5. **Sending a turn** (`sendUtterance(text)`): guard empty; push user `VoiceTurn`; dispatch `utteranceReady`; **stop recognition** (`.stop()` + null the ref — the mic must be off before any TTS starts); build history from `turns` (`{role, content}` pairs) + the new user text; `fetch('/api/assistant/chat', { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({ messages, voice: true }), signal })` with a fresh AbortController; parse SSE exactly like `FloatingChatPanel.tsx:228-269` (split on `\n\n`, `data: ` prefix, JSON.parse per frame):
   - `text` → append to `streamingText` AND feed `chunker.push(delta)`; each returned sentence → `speak(sentence)`.
   - `status` → `setStatusKey(key)`.
   - `job_created` → stash `{id, title}` for the pending assistant turn.
   - `error` → `setErrorKey('voiceError')`. Errors are **shown, never spoken** (keeps `t()` out of the hook); the mic reopens on the normal `streamEnded`/`speechDrained` path so the user can simply repeat themselves.
   - `done` → ignore (reader close is the signal, matching existing clients).
   - On reader completion: `chunker.flush()` → speak tail; finalise the assistant `VoiceTurn` (content = full streamed text, jobCard if any); clear `streamingText`/`statusKey`; dispatch `streamEnded`.
   - On catch: if aborted → dispatch `streamEnded` + `speechDrained` silently; else `setErrorKey('voiceError')`, finalise whatever streamed, dispatch `streamEnded` + `speechDrained`.
6. **`speak(rawSentence)`**: `const s = toSpeakable(rawSentence); if (!s) return;` create utterance, `lang = speechLangTag(lang)`, `voice = pickVoice(voices, tag)` (cast the picked `SpeakableVoice` back by matching `voiceURI`/`name` in the real list), increment queue counter, `onend`/`onerror` decrement — when the counter hits 0 AND the stream has finished, dispatch `speechDrained`. If `!supported.tts` or no voice: skip speaking entirely and rely on text — dispatch `speechDrained` when the stream ends (the reducer still needs both flags; simplest: when TTS is unavailable dispatch `speechDrained` immediately after `streamEnded`).
7. **Phase effects:** a `useEffect` on `phase`: entering `listening` → ensure recognition running (create if needed); entering `responding`/`muted`/`tapToTalk` → ensure recognition stopped. Entering `listening` also clears `errorKey`.
8. **`mute()`/`unmute()`** dispatch; **`tapTalk()`**: in `tapToTalk` phase, start a one-shot recognition (`continuous = false`) whose final result sends immediately (no silence timer); **`sendTyped(text)`**: calls `sendUtterance(text)` directly.
9. **`shutdown()`**: abort in-flight fetch; stop recognition; `speechSynthesis.cancel()`; clear timers; save the conversation — POST `/api/assistant/save` with `keepalive: true` and payload `messages: turns.map(({role, content, jobCard}) => ({role, content, ...(jobCard ? {jobCard} : {})}))` when `turns.length >= 2` (mirror `FloatingChatPanel.tsx:139-153`).
10. **Unmount effect** calls `shutdown()` (ref-guarded so double-invoke is safe).

Size guard: keep under ~350 lines; if it grows past that, split the SSE consumption into `src/features/voice/streamTurn.ts`.
