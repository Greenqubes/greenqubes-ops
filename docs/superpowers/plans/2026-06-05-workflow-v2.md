# Workflow V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce 3 new roles (designer, coordinator, production), remove the approval workflow in favour of direct sales→schedule push with FCFS clash detection, add a Scheduler FCFS Board tab, support installer suggestions by sales, formal assignment by coordinator/scheduler, external installer temp links, sub-installer relationships, and a task list bucket.

**Architecture:** Built in 4 independent phases on the `feat-workflow-v2` branch — each phase ships testable software. Phase 1 (roles + workflow) is a prerequisite for all others. Phases 2–4 can be worked in any order after Phase 1. No new npm packages required. All DB changes land in numbered Supabase migrations.

**Tech Stack:** Next.js 15 (App Router), TypeScript strict, Tailwind, Supabase (Postgres + RLS + Realtime), Cloudflare R2, Anthropic Claude, Telegram Bot API.

**Assumptions documented here (confirm with Nic if unsure):**
- Coordinator also has access to the FCFS Board tab (they assign installers, need to see clashes)
- Designer and Production can see all scheduled jobs in the Schedule list (view only)
- Production role users see schedule list but can only edit their specific fields in job form
- "awaiting_approval" is kept in the DB enum but no new jobs will enter that state (for historical data safety)
- A job can have multiple coordinators (via existing `job_coordinators` join table from migration 0029)
- External installer temp link is generated manually by coordinator/scheduler from within the job form

## PHASE 1: Role Infrastructure + Workflow Simplification

**What this delivers:** 3 new DB roles, deprecated approval workflow (sales pushes directly to scheduled), new Telegram notification to scheduler on new job, updated nav per role, admin role management updated. After this phase the app builds and all roles can sign in — new roles land on schedule page.

> **✅ PHASE 1 IMPLEMENTED — 2026-06-11.** Deviations from the plan as written:
> - Migration split into **0033** (enum values + job_assignees columns) and **0034** (RLS policies) — new enum values can't be used in the same transaction that creates them (same split as 0018/0019). Both applied to remote DB.
> - Role routing lives in `src/app/page.tsx`, not the auth callback (callback just redirects to `/`).
> - `ApprovalsShell.tsx` was deleted too (it imported ApprovalCard/SendBackModal and called the deleted routes — keeping it broke the build). `queries/approvals.ts` + approval i18n strings left as dead code for Phase 3 cleanup.
> - **FCFS tab added to BottomNav for every role** (Nic's decision from mockup review), not just scheduler/coordinator.
> - Sales "Recall" button and awaiting_approval form-lock removed from JobDetailShell; orphaned Telegram templates (submitted-for-approval / approved / sent-back) deleted.
> - **Hotfix 0035:** the `suggested_by` FK to users gave `job_assignees` two relationships to `users`, so every `job_assignees ( users (...) )` embed failed with PGRST201 — crashed /schedule on all deployments. FK dropped (column kept, app-level validation). ⚠️ Phase 2: if querying `suggested_by` with an embed, or re-adding the FK, all embeds must use the explicit form `users!job_assignees_user_id_fkey (...)`.

- [ ] **Step 3: Create suggest-installer API route**

```typescript
// src/app/api/jobs/[id]/suggest-installer/route.ts
import { createRouteHandlerClient } from '@/lib/supabase/server'
import { NextRequest, NextResponse } from 'next/server'

export async function POST(req: NextRequest, { params }: { params: { id: string } }) {
  const supabase = createRouteHandlerClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const { data: profile } = await supabase
    .from('users').select('id, role').eq('auth_id', user.id).single()
  if (profile?.role !== 'sales')
    return NextResponse.json({ error: 'Forbidden' }, { status: 403 })

  const { user_id, action } = await req.json()
  const jobId = params.id

  if (action === 'add') {
    await supabase.from('job_assignees').upsert({
      job_id:       jobId,
      user_id,
      is_suggestion: true,
      suggested_by:  profile.id,
    }, { onConflict: 'job_id,user_id' })
  } else {
    await supabase.from('job_assignees')
      .delete()
      .eq('job_id', jobId)
      .eq('user_id', user_id)
      .eq('is_suggestion', true)
  }

  return NextResponse.json({ ok: true })
}
```

import { NextRequest, NextResponse } from 'next/server'
import { tplInstallerAssigned } from '@/lib/telegram/templates'
import { sendTelegramMessage } from '@/lib/telegram/bot'

export async function POST(req: NextRequest, { params }: { params: { id: string } }) {
  const supabase = createRouteHandlerClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const { data: profile } = await supabase
    .from('users').select('id, role').eq('auth_id', user.id).single()
  if (!['scheduler', 'coordinator', 'admin'].includes(profile?.role ?? ''))
    return NextResponse.json({ error: 'Forbidden' }, { status: 403 })

  const jobId = params.id

  // 1. Delete all suggestions for this job
  await supabase.from('job_assignees')
    .delete()
    .eq('job_id', jobId)
    .eq('is_suggestion', true)

  // 2. Delete existing formal assignments
  await supabase.from('job_assignees')
    .delete()
    .eq('job_id', jobId)
    .eq('is_suggestion', false)

  // 3. Insert new formal assignments
  if (installer_ids.length > 0) {
    await supabase.from('job_assignees').insert(
      installer_ids.map((uid: string) => ({
        job_id: jobId,
        user_id: uid,
        is_suggestion: false,
        is_sub_installer: false,
      }))
    )
  }

  // 4. Notify sales POC + coordinators
  const { data: job } = await supabase
    .from('jobs')
    .select('id, project_title, client, date, location, sales_poc:users!sales_poc_id(telegram_chat_id, name)')
    .eq('id', jobId)
    .single()

  const { data: installers } = await supabase
    .from('users').select('name').in('id', installer_ids)

  const { data: coordinators } = await supabase
    .from('job_coordinators')
    .select('users(telegram_chat_id)')
    .eq('job_id', jobId)

  const installerNames = installers?.map(i => i.name).join(', ') ?? ''
  const appUrl = process.env.NEXT_PUBLIC_APP_URL ?? ''
  const msg = tplInstallerAssigned({ job, installerNames, appUrl })

  const recipients = [
    (job?.sales_poc as any)?.telegram_chat_id,
    ...(coordinators?.map((c: any) => c.users?.telegram_chat_id) ?? []),
  ].filter(Boolean)

  for (const chatId of recipients) {
    await sendTelegramMessage(chatId, msg)
  }

  return NextResponse.json({ ok: true })
}

export interface FCFSJob {
  id:            string
  project_title: string
  client:        string
  date:          string        // YYYY-MM-DD
  time_start:    string        // HH:MM:SS
  time_end:      string | null
  punctuality:   'strict' | 'flexible'
  fcfs_rank:     number        // row_number() by created_at asc
  assignees: {
    user_id:        string
    name:           string
    is_suggestion:  boolean
    is_sub_installer: boolean
  }[]
}

export async function getFCFSWeek(
  supabase: SupabaseClient,
  weekStart: string, // YYYY-MM-DD (Monday)
  weekEnd: string    // YYYY-MM-DD (Sunday)
): Promise<FCFSJob[]> {
  const { data } = await supabase
    .from('jobs')
    .select(`
      id, project_title, client, date, time_start, time_end, punctuality, created_at,
      job_assignees(user_id, is_suggestion, is_sub_installer,
        users(name))
    `)
    .eq('status', 'scheduled')
    .gte('date', weekStart)
    .lte('date', weekEnd)
    .order('created_at', { ascending: true })

  if (!data) return []

  return data.map((job, idx) => ({
    id:            job.id,
    project_title: job.project_title,
    client:        job.client,
    date:          job.date,
    time_start:    job.time_start,
    time_end:      job.time_end,
    punctuality:   (job as any).punctuality ?? 'flexible',
    fcfs_rank:     idx + 1,
    assignees:     (job.job_assignees as any[]).map(a => ({
      user_id:          a.user_id,
      name:             a.users?.name ?? 'Unknown',
      is_suggestion:    a.is_suggestion,
      is_sub_installer: a.is_sub_installer,
    })),
  }))
}

```typescript
// src/lib/utils/clashDetection.ts
import { FCFSJob } from '@/lib/supabase/queries/fcfs'

// Clash types:
//   'hard'  — strict + strict: both jobs require on-time, must resolve
//   'soft'  — flexible + strict (either order): soft warning only, no blocking
//   flex + flex: no clash at all, skip entirely

export type ClashType = 'hard' | 'soft'

export interface Clash {
  installerId:   string
  installerName: string
  date:          string
  type:          ClashType
  jobA:          FCFSJob   // earlier FCFS rank (priority)
  jobB:          FCFSJob   // later FCFS rank
}

function toMinutes(time: string): number {
  const [h, m] = time.split(':').map(Number)
  return h * 60 + m
}

function overlaps(a: FCFSJob, b: FCFSJob): boolean {
  if (!a.time_end || !b.time_end) return false
  const aStart = toMinutes(a.time_start)
  const aEnd   = toMinutes(a.time_end)
  const bStart = toMinutes(b.time_start)
  const bEnd   = toMinutes(b.time_end)
  return aStart < bEnd && bStart < aEnd
}

function getClashType(a: FCFSJob, b: FCFSJob): ClashType | null {
  const aStrict = a.punctuality === 'strict'
  const bStrict = b.punctuality === 'strict'
  if (aStrict && bStrict)  return 'hard'
  if (!aStrict && !bStrict) return null  // flex + flex = no clash
  return 'soft'                          // one strict, one flexible = soft warning
}

export function detectClashes(jobs: FCFSJob[]): Clash[] {
  const clashes: Clash[] = []

  for (let i = 0; i < jobs.length; i++) {
    for (let j = i + 1; j < jobs.length; j++) {
      const a = jobs[i]
      const b = jobs[j]
      if (a.date !== b.date) continue
      if (!overlaps(a, b)) continue

      const clashType = getClashType(a, b)
      if (!clashType) continue  // flex + flex, skip

      // Find shared formal assignees (non-suggestion, non-sub)
      const aAssigned = a.assignees.filter(x => !x.is_suggestion && !x.is_sub_installer)
      const bAssigned = b.assignees.filter(x => !x.is_suggestion && !x.is_sub_installer)

      for (const aA of aAssigned) {
        const shared = bAssigned.find(bA => bA.user_id === aA.user_id)
        if (shared) {
          clashes.push({
            installerId:   aA.user_id,
            installerName: aA.name,
            date:          a.date,
            type:          clashType,
            jobA:          a.fcfs_rank <= b.fcfs_rank ? a : b,
            jobB:          a.fcfs_rank <= b.fcfs_rank ? b : a,
          })
        }
      }
    }
  }

  return clashes
}
```

    .select('*')
    .eq('job_id', params.id)
    .order('sort_order')

  return NextResponse.json(data ?? [])
}

// POST — add a task (sales/coordinator/scheduler/admin)
export async function POST(req: NextRequest, { params }: { params: { id: string } }) {
  const supabase = createRouteHandlerClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const { data: profile } = await supabase
    .from('users').select('id, role').eq('auth_id', user.id).single()
  if (!['sales','scheduler','coordinator','admin'].includes(profile?.role ?? ''))
    return NextResponse.json({ error: 'Forbidden' }, { status: 403 })

  const { text } = await req.json()
  const { data: maxOrder } = await supabase
    .from('job_tasks').select('sort_order').eq('job_id', params.id).order('sort_order', { ascending: false }).limit(1).single()

  const { data: task } = await supabase.from('job_tasks').insert({
    job_id: params.id,
    text,
    created_by: profile.id,
    sort_order: (maxOrder?.sort_order ?? -1) + 1,
  }).select().single()

  return NextResponse.json(task)
}

// PATCH — toggle completion (installer) or update text (scheduler/coordinator)
export async function PATCH(req: NextRequest, { params }: { params: { id: string } }) {
  const supabase = createRouteHandlerClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const { data: profile } = await supabase
    .from('users').select('id, role').eq('auth_id', user.id).single()

  const { task_id, is_completed, text } = await req.json()

  if (is_completed !== undefined) {
    // Installer/sub-installer ticking off
    await supabase.from('job_tasks').update({
      is_completed,
      completed_by: is_completed ? profile.id : null,
      completed_at: is_completed ? new Date().toISOString() : null,
    }).eq('id', task_id)
  }

  if (text !== undefined && ['sales','scheduler','coordinator','admin'].includes(profile?.role ?? '')) {
    await supabase.from('job_tasks').update({ text }).eq('id', task_id)
  }

  return NextResponse.json({ ok: true })
}

// DELETE — remove a task (sales/coordinator/scheduler/admin)
export async function DELETE(req: NextRequest, { params }: { params: { id: string } }) {
  const supabase = createRouteHandlerClient()

'use client'
import { useEffect, useState } from 'react'

interface Task { id: string; text: string; is_completed: boolean; sort_order: number }

interface TaskListSectionProps {
  jobId: string
  role:  Role
}

export default function TaskListSection({ jobId, role }: TaskListSectionProps) {
  const [tasks, setTasks]   = useState<Task[]>([])
  const [newText, setNewText] = useState('')

  const canAdd    = (['sales','scheduler','coordinator','admin'] as Role[]).includes(role)
  const canTick   = (['installer','scheduler','coordinator','admin','sales'] as Role[]).includes(role)
  const canDelete = (['sales','scheduler','coordinator','admin'] as Role[]).includes(role)

  useEffect(() => {
    fetch(`/api/jobs/${jobId}/tasks`)
      .then(r => r.json()).then(setTasks)
  }, [jobId])

  const addTask = async () => {
    if (!newText.trim()) return
    const res = await fetch(`/api/jobs/${jobId}/tasks`, {
      method: 'POST', headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ text: newText.trim() }),
    })
    const task = await res.json()
    setTasks(prev => [...prev, task])
    setNewText('')
  }

  const toggleTask = async (taskId: string, current: boolean) => {
    setTasks(prev => prev.map(t => t.id === taskId ? { ...t, is_completed: !current } : t))
    await fetch(`/api/jobs/${jobId}/tasks`, {
      method: 'PATCH', headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ task_id: taskId, is_completed: !current }),
    })
  }

  const deleteTask = async (taskId: string) => {
    setTasks(prev => prev.filter(t => t.id !== taskId))
    await fetch(`/api/jobs/${jobId}/tasks`, {
      method: 'DELETE', headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ task_id: taskId }),
    })
  }

  return (
    <div className="rounded-xl border border-line bg-paper p-4">
      <h3 className="text-sm font-semibold text-ink mb-3">Task List</h3>

      {tasks.length === 0 && !canAdd && (
        <p className="text-xs text-muted">No tasks added yet.</p>
      )}

      <div className="space-y-2">
        {tasks.map(task => (
          <div key={task.id} className="flex items-center gap-2">
            <input
              type="checkbox"
              checked={task.is_completed}
              disabled={!canTick}
              onChange={() => toggleTask(task.id, task.is_completed)}
              className="w-4 h-4 accent-terracotta"
            />
            <span className={`text-sm flex-1 ${task.is_completed ? 'line-through text-muted' : 'text-ink'}`}>
              {task.text}
            </span>
            {canDelete && (
              <button onClick={() => deleteTask(task.id)} className="text-muted hover:text-terracotta text-xs">✕</button>
            )}
          </div>
        ))}
      </div>

      {canAdd && (
        <div className="flex gap-2 mt-3">
          <input
            className="flex-1 text-sm border border-line rounded-lg px-3 py-1.5 bg-bg text-ink"
            placeholder="Add a task…"
            value={newText}
            onChange={e => setNewText(e.target.value)}
            onKeyDown={e => e.key === 'Enter' && addTask()}
          />
          <button
            onClick={addTask}
            className="text-sm px-3 py-1.5 bg-terracotta text-white rounded-lg"
          >
            Add
          </button>
        </div>
      )}
    </div>
  )
}

'use client'
import { useEffect, useState } from 'react'
import { Role } from '@/lib/supabase/types'

interface ExtContact {
  id:          string
  name:        string
  phone:       string
  token:       string
  deleted_at:  string | null
  job_count:   number   // past jobs count — derived from job_external_contacts
  assigned:    boolean  // true if already linked to this job
}

interface ExternalPOCBucketProps {
  jobId: string
  role:  Role
}

export default function ExternalPOCBucket({ jobId, role }: ExternalPOCBucketProps) {
  const [contacts,    setContacts]    = useState<ExtContact[]>([])
  const [showAdd,     setShowAdd]     = useState(false)
  const [newName,     setNewName]     = useState('')
  const [newPhone,    setNewPhone]    = useState('')
  const [deleting,    setDeleting]    = useState<string | null>(null)   // contact id pending confirm
  const [restoring,   setRestoring]   = useState<string | null>(null)
  const canEdit = (['scheduler','coordinator','admin'] as Role[]).includes(role)
  const appUrl  = process.env.NEXT_PUBLIC_APP_URL ?? ''

  useEffect(() => {
    // Fetch all contacts + which are assigned to this job
    Promise.all([
      fetch('/api/external-contacts').then(r => r.json()),
      fetch(`/api/jobs/${jobId}/external-contacts`).then(r => r.json()),
    ]).then(([all, assigned]: [ExtContact[], { contact_id: string }[]]) => {
      const assignedIds = new Set(assigned.map(a => a.contact_id))
      setContacts(all.map(c => ({ ...c, assigned: assignedIds.has(c.id) })))
    })
  }, [jobId])

  const assignContact = async (contactId: string) => {
    await fetch(`/api/jobs/${jobId}/external-contacts`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ contact_id: contactId }),
    })
    setContacts(prev => prev.map(c => c.id === contactId ? { ...c, assigned: true } : c))
  }

  const addNewContact = async () => {
    if (!newName.trim()) return
    const res = await fetch('/api/external-contacts', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ name: newName.trim(), phone: newPhone.trim() }),
    })
    const contact = await res.json()
    // Auto-assign the newly created contact to this job
    await fetch(`/api/jobs/${jobId}/external-contacts`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ contact_id: contact.id }),
    })
    setContacts(prev => [...prev, { ...contact, job_count: 0, assigned: true }])
    setNewName('')
    setNewPhone('')
    setShowAdd(false)
  }

  const deleteContact = async (contactId: string) => {
    await fetch(`/api/external-contacts/${contactId}`, { method: 'DELETE' })
    setContacts(prev => prev.map(c =>
      c.id === contactId ? { ...c, deleted_at: new Date().toISOString() } : c
    ))
    setDeleting(null)
  }

  const restoreContact = async (contactId: string) => {
    await fetch(`/api/external-contacts/${contactId}`, { method: 'PATCH' })
    setContacts(prev => prev.map(c =>
      c.id === contactId ? { ...c, deleted_at: null } : c
    ))
    setRestoring(null)
  }

  const active  = contacts.filter(c => !c.deleted_at)
  const deleted = contacts.filter(c =>  c.deleted_at)

  return (
    <div className="mt-3 rounded-xl border border-amber-200 bg-amber-50 p-4 space-y-3">
      <p className="text-xs font-semibold text-amber-700 uppercase tracking-wide">External Installers</p>

      {/* Active contacts */}
      {active.map(c => (
        <div key={c.id} className="rounded-lg border border-line bg-paper p-3">
          <div className="flex items-center justify-between mb-1">
            <div>
              <p className="text-sm font-medium text-ink">{c.name}</p>
              <p className="text-xs text-muted">{c.phone} · {c.job_count} past job{c.job_count !== 1 ? 's' : ''}</p>
            </div>
            {canEdit && (
              <div className="flex items-center gap-2">
                {c.assigned ? (
                  <span className="text-xs text-green-600 font-medium">Assigned</span>
                ) : (
                  <button onClick={() => assignContact(c.id)}
                    className="text-xs px-2 py-1 rounded-lg bg-terracotta text-white">Assign</button>
                )}
                <button onClick={() => setDeleting(c.id)}
                  className="text-xs text-muted hover:text-terracotta">Delete</button>
              </div>
            )}
          </div>

          {/* Delete confirmation inline */}
          {deleting === c.id && (
            <div className="mt-2 p-2 rounded-lg bg-red-50 border border-terracotta text-xs">
              <p className="text-terracotta font-medium mb-1">
                This will immediately invalidate their link.
                {c.job_count > 0 && ` ${c.job_count} active job${c.job_count !== 1 ? 's' : ''} affected.`}
              </p>
              <div className="flex gap-2">
                <button onClick={() => deleteContact(c.id)}
                  className="px-2 py-1 rounded bg-terracotta text-white">Confirm Delete</button>
                <button onClick={() => setDeleting(null)}
                  className="px-2 py-1 rounded border border-line bg-paper text-ink2">Cancel</button>
              </div>
            </div>
          )}
        </div>
      ))}

      {/* Deleted contacts — restore button */}
      {deleted.map(c => (
        <div key={c.id} className="rounded-lg border border-line bg-paper p-3 opacity-60">
          <div className="flex items-center justify-between">
            <p className="text-sm text-muted line-through">{c.name}</p>
