## What was done

### Full workflow v2 redesign

Nic shared a workflow diagram from a team meeting. Discussed and clarified the entire new system across ~20 back-and-forth exchanges. Key decisions locked in:

**New roles (7 total):**
- **Designer** — view all job fields, edit only: production instructions + attachments + chat. No completion rights.
- **Coordinator** — assigns installers formally, receives overdue notifications (not FCFS clash).
- **Production** — tick "Production ready" + "DO issued", edit production instructions, upload production photos, view attachments + chat.
- Existing: sales, scheduler, installer, admin unchanged.

**Approval workflow removed entirely:**
- Jobs go directly `pending → scheduled` when sales pushes.
- No more `awaiting_approval` status in new flow (kept in DB enum for historical data).
- Approve/send-back API routes deleted.
- Scheduler's Approvals tab replaced by FCFS Board.

**Installer assignment flow:**
- Sales can *suggest* installers (yellow card + "Sales suggest this installer" subtext) — no real assignment rights.
- Coordinator/Scheduler formally assign (green card, clears all yellow suggestions).
- Post-assignment: Telegram notification fires to sales POC + all job coordinators.
- When sales pushes to schedule: Telegram fires to all schedulers ("New job — please assign installer").

**FCFS Board (replaces Approvals tab for scheduler + coordinator):**
- Weekly timeline grid: rows = installers, columns = days.
- FCFS rank badge (#1, #2…) on each job block by creation date.
- Clashing jobs (same installer, overlapping time) highlighted red.
- Clash banner at top with "View Details" → slide-up drawer.
- Drawer shows both clashing jobs side by side, Re-assign + Dismiss actions.
- No "Alert Scheduler" button on this page (scheduler is already looking at it).

**Coordinator clash prompt (in job form):**
- When coordinator assigns an installer that clashes: modal appears.
- Two options: "Alert Scheduler" (in-app + Telegram) or "Re-assign".

**External installer temp link:**
- 48-hour single-use link generated by scheduler/coordinator from job form.
- External page: view-only job summary, chat (read), photo upload to `external_verification` bucket.
- Expired: "Job link expired. Please WhatsApp the respective person in-charge directly. Thank you."
- No login required. Excluded from auth middleware.

**External Installer POC bucket (placeholder card in InstallerGrid):**
- Static "External Installers" card (not a user role) in the InstallerGrid.
- When selected: reveals `ExternalInstallerBucket` with per-team rows.
- Each row: POC name + contact number + quantity (no. of installers).
- "Add another POC" button for multiple outsourced teams.
- Stored in new `job_external_installers` table (one row per team per job).

**Sub-installer relationship:**
- Sub-installers are existing installer-role users assigned as supporting workers within a job.
- New `SubInstallerSection` in job form, separate from main InstallerGrid.
- Stored via `is_sub_installer = true` on `job_assignees`.

**Task list bucket:**
- Checklist input by sales/coordinator/scheduler.
- Ticked off by installer/sub-installer.
- Shown in job form for all roles.
- Stored in new `job_tasks` table.
